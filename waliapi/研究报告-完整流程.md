## 2. 打包结构 (照 octopus 模式)

```
waliapi/
├── ICON.PNG / ICON_256.PNG
├── README.md              # 打包说明+安装方式
├── waliapi.fpk            # 63.8MB
├── src/                   # 上游源码 fork (github.com/fuzhengwei/WaLiAPI, 去嵌套 .git, 414 文件)
├── app/
│   ├── bin/waliapi-web    # 30MB 镜像提取,未修改
│   ├── lib/               # webkit2gtk-4.1 三件套 + GTK3 + 传递依赖 ~20 个 so (bookworm 版)
│   │   └── webkit2gtk-4.1/  # webkit 进程辅助程序目录
│   └── ui/                # (面板内嵌二进制,ui 仅 fnOS 入口 config)
├── cmd/                   # main(start/stop/status) + install/uninstall/upgrade + config 脚本
├── config/
├── wizard/
└── manifest               # appname=waliapi version=0.2.5 service_port=8777 install_type=root
```

- `cmd/main`: `LD_LIBRARY_PATH=$APP_DIR/lib:$APP_DIR/lib/webkit2gtk-4.1`,WALIAPI_SERVER_PORT=8777,WALIAPI_DATA_DIR=$APP_DIR/data,XDG 目录落 /var/apps/waliapi/var/
- 宿主机零依赖: 全走 fpk 自带库,不碰 apt (本机 apt 源为空)
